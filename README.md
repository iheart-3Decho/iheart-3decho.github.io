# iHeart

**3D Analysis & Visualization**

Website: [iheart-3decho.github.io](https://iheart-3decho.github.io/)

A minimal, responsive title page for iHeart. The site uses static HTML, inline CSS and an SVG favicon, with no build dependencies.

GitHub Pages publishes the repository root from the `main` branch. Push changes to `main` to update the site.

For a local preview, run `python3 -m http.server 8080` in this directory and open `http://localhost:8080`.
