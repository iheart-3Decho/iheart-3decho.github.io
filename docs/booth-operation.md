# iHeart 展台操作說明

## 現場啟動

在網站目錄執行 `pnpm install --frozen-lockfile`、`pnpm build`、`pnpm preview`，開啟 http://127.0.0.1:4173/。瀏覽器使用 1920 × 1080 畫面和全螢幕，縮放 100%。保持本地靜態服務運行；影片、圖片與說明都在 `dist/`，斷開外部網路也能完成體驗。不要直接以 `file://` 開啟，也不需要模型伺服器。

預設首頁是展台互動入口。`#/showcase` 保留原六項量測展示；原 `#/case/…` 詳情連結不變。網站未增加平台安裝或開機自啟動工具。

## 一輪體驗

待機畫面每 12 秒交替展示泵血與尺寸病例，先靜音播放影片，再呈現對應量測畫面。觀眾開始後停止輪播，自己控制播放、慢放、時間軸與逐幀調整。系統要求減少動效時，待機影片改為手動播放。

泵血任務：選心室充盈最大畫面，再選收縮後最小畫面。兩個畫面不能相同，但不限制先後。點「開始 AI 分析」揭示預置結果。畫面並排展示你的選擇與 AI 選擇；輪廓只放在對應的 AI 畫面上。你的選帧不生成 EF 或容積預測。

尺寸任務：預設充盈期內徑，也可選收縮期內徑、室間隔或後壁厚度。選畫面後點兩端；拖動端點、方向鍵微調或清除重畫。結果中的兩條線各自位於自己的畫面，不直接重疊。觀眾畫線不換算為毫米；AI 數值保留模型最終時間證據聚合結果。

各步可返回修改。結果頁可再試一次、換另一項或返回首頁。影片包含多次心跳，對照不提供正確／錯誤评分，也不將 AI 當醫生金標準。

## 復位與故障

互動中 120 秒沒有點擊、鍵盤或滑桿操作，就顯示 15 秒倒數；點「繼續體驗」取消倒數。否則清空本輪畫面、端點與選項，回到待機。影片播放和動畫不延長閒置時間。資料只存於記憶體，刷新也會清除。影片或 AI 圖片未載入時提供重試，不會自動確認答案。

## 驗收命令

保持靜態預覽運行，另開終端執行：

```bash
pnpm check:data
pnpm check:experience
pnpm check:browser
pnpm check:soak
```

`check:experience` 檢查完整流程、四項尺寸、返回修改、重畫、拖動與鍵盤、閒置及取消復位、100 次完整互動／復位、同源靜態資源和單屏截圖。截取的原始畫面與 ffmpeg 解碼的同幀 MP4 像素比對。閒置測試使用瀏覽器時間控制加速；與實際時間的待機測試分開。

`check:browser` 回歸原首頁及六個病例入口。`check:soak` 預設實際運行至少 8 小時，每分鐘檢查影片、頁面尺寸、錯誤、GC 後 JS heap、DOM 與監聽器。只有真實運行滿時數才記錄 passed。`SOAK_HOURS` 僅供短程調試，不算 8 小時驗收。

報告和逐頁截圖保存在本地 `private-source/booth-validation/`，不進入公開部署。任何運行中的報告都不是完成證明。最終 `dist/` 包含完整前端與已授權展示素材。
