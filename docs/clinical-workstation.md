# iHeart 臨床分析工作站演示版

## 本地開啟

在網站目錄執行：

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm preview
```

開啟 http://127.0.0.1:4173/，或 http://127.0.0.1:4173/#/clinical。以 1920 × 1080、瀏覽器 100% 縮放與全螢幕閱覽；頁面無滾動。`dist/` 包含靜態頁面及共用的既有病例素材。開發模式使用 `pnpm dev`，連接埠為 5173。2026-10-23 已部署至 [STG 演示機](stg-deployment.md)，由桌面快捷方式手動全螢幕啟動，關閉後不重啟；GitHub Pages 本輪未更新。

保留入口：

| 入口               | 內容                                     |
| ------------------ | ---------------------------------------- |
| `#/`、`#/clinical` | 新版臨床分析工作站                       |
| `#/experience`     | 原互動展台，選幀、畫線與對照流程保持獨立 |
| `#/showcase`       | 原六項量測展示首頁                       |

## 操作

左側是六個匿名檢查；中間為影片和證據圖；右側為量測表。選擇未分析病例後播放原始影片，點「AI 分析」揭示該病例已有模型結果。點「生成報告」後，右側原位顯示固定格式的心臟超聲量測報告，不必先確認量測，也不會彈窗或遮住影片。點報告內的證據圖可直接定位中間的影片，報告仍留在原位；需要時才按「返回量測」。

點量測行，影片會暫停到對應時刻，顯示該幀自己的輪廓或測量線。功能病例可切換 ED／ES 證據圖，亦可點容積曲線的實際輸出點定位。尺寸病例提供四項量測證據圖。播放、慢放、逐幀、重播、時間軸、原始／AI 切換均可操作；離開有預測支持的畫面，疊加即隱藏。

「確認量測」只記錄本輪核查狀態，可再次點擊撤回；重新分析會清除該病例的確認狀態。報告包含當前匿名檢查編號、切面、量測數值與單位、證據圖及核查狀態。功能報告列 EF、EDV、ESV；尺寸報告列 IVSd、LVIDd、LVIDs、LVPWd，不跨病例合併。

### 流程提示與過渡

影像上方常駐「檢視影片 → 定位與量測 → 整理報告」三步提示，並用一句短說明交代當前畫面的用途。分析後，實際量測位置淡入並短暫高亮，證據圖與數值依次顯現；容積曲線沿已有輸出點展開。切換指標會再次突出對應位置，不改變預測坐標，也不讓數字從零跳算。

報告在右側淡入，工作區用約 700 毫秒平滑調整欄寬，影片始終可見；切換病例時新影片淡入。轉場約 150–900 毫秒，可隨時接管或切換病例。這些是既有結果的呈現效果，不是模擬推理進度；啟用系統「減少動效」時不播放上述動畫。

報告提供「列印報告」，呼叫瀏覽器列印對話框，可選擇印表機或瀏覽器內建的儲存 PDF。沒有額外 PDF 引擎。工作站與內嵌報告共用同一頁，可隨時切換病例和播放影片；使用 Tab、Enter／空白鍵操作按鈕，時間軸可用方向鍵調整。

## 自動演示與復位

預設開啟 EchoXFlow `recording_f253dc88013d7a95`（IH-003）並啟動八段輪播；每段 12 秒，先播放原片 5 秒，接著顯示量測與證據位置 3 秒，最後 4 秒自動在同頁展示報告。段落沿用 `public/experience/experience.json` 的 `playlist`，涵蓋六個病例與七項指標。整輪不用操作者點擊；不同切面屬不同示範病例。

點擊或鍵盤操作立即接管，病例不再自動切換。「恢復自動演示」清除本輪核查並從第一段開始。手動狀態下連續 120 秒無操作，關閉報告、清除核查狀態並恢復輪播。影片播放及動畫不延長閒置時間。系統啟用減少動效時，預設手動、影片暫停，且不因閒置自動恢復；使用者仍可明確按鈕啟動演示。

影片載入失敗時停止自動切換，提供「重新載入影片」。證據圖載入失敗時可單獨重試。切換病例、離開工作站或關閉報告時清理對應播放器、動畫回呼、計時器和監聽器。狀態僅存記憶體，重新整理清除。

## 資料與影像規則

工作站直接共用 `public/demo/cases.json` 的數值、單位及證據幀幾何，以及 `public/experience/experience.json` 的實際證據圖片。未改寫舊版病例資料或展台會話邏輯。六例來源與模型 checkpoint 見[病例庫說明](case-library.md)。檢查編號 IH-001 至 IH-006 僅為列表序號，不新增姓名或醫院資料。

疊加坐標使用已還原到播放影片坐標系的預測點，SVG 與影片採相同尺寸比例。疊加只在影片暫停、解碼完成且當前幀與證據幀一致時出現；沒有把固定輪廓貼到整段影片上。所有定位使用實際播放幀率與幀索引。TED 缺少已核實的採集幀率，維持以心動週期百分比顯示，不把展示速度換算成生理時間。

容積曲線直接繪製 `volumeSeries` 的既有模型輸出點；相鄰點間僅以折線連接，沒有補造逐幀輸出。最終 EF／EDV／ESV 保留模型的功能分支結果，並非從展示用曲線或輪廓重新計算。EF 量測表標明 ED / ES；選取 EF 時先定位 ED，亦可在下方查看 ES。

「AI 分析」顯示已預置的真實推理結果；瀏覽器沒有模型服務、上傳流程或模擬推理進度。報告呈現量測和證據，不自動生成疾病結論。

## 驗收

保持 `pnpm preview` 運行，在另一個終端執行：

```bash
pnpm lint
pnpm check:types
pnpm check:data
pnpm build
pnpm check:clinical
pnpm check:clinical-motion
pnpm check:browser
pnpm check:library
pnpm check:experience
```

新版檢查覆蓋六例切換、分析、所有指標定位、原始／AI 切換、逐幀、未核查及已核查報告、八段自動演示與循環、人工接管、120 秒閒置恢復、減少動效和影片失敗重試。逐幀索引及 SVG 點坐標與既有匯出資料核對；功能與尺寸報告另輸出 A4 列印樣本。

資源檢查先暖機，再執行 60 次病例分析／開關報告和 12 次工作站／舊展台路由切換，比較 GC 後 JavaScript heap、DOM 節點和事件監聽器。計時器測試使用受控瀏覽器時鐘；這些檢查不等同真實 8 小時長時間待機測試。

動效另用原生瀏覽器時間檢查，核對動畫確實播放、報告淡入的中間狀態、120px 欄寬變化、轉場中切換病例、減少動效及完整 12 秒自動演示段落。相關截圖及機器記錄在 `private-source/clinical-validation/motion/`，不以受控時鐘下的最終截圖代替真實動效驗證。

新版驗收報告、1920 × 1080 截圖及列印樣本保存於本地 `private-source/clinical-validation/`；舊頁回歸保存於原驗收目錄。正式源碼在 `src/clinical/` 與 `src/components/clinical/`，樣式以 Tailwind utilities 組成。
